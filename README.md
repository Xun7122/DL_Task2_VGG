## 실험 상태

**아직 GPU 학습하지 않은 후보입니다. 성능 향상을 확인한 버전이 아닙니다.** `main`의 첫 VGG와 이전 개선 브랜치는 보존합니다.

| 기존 첫 모델의 검증 지표 | 값 |
|---|---:|
| BA @ 0.5 | 0.740966 |
| 기존 0.10~0.90 임계값 탐색 BA | 0.755725 |
| 동일 예측값의 전체 ROC 임계값 탐색 BA | 0.758088 |
| AUROC | 0.826996 |

마지막 두 BA의 차이는 재학습의 효과가 아니라 임계값 탐색 범위 차이입니다. 새 후보는 전체 ROC 임계값을 사용하므로 BA 0.758088과 비교합니다. 기존 예측에서 구한 임계값은 약 0.00557664이며 원래 가중치의 진단 결과일 뿐 새 모델의 임계값이 아닙니다.

## 설계

- ImageNet 사전학습 VGG11의 원래 합성곱/FC 구조를 유지하고 출력층만 2개 클래스로 교체합니다.
- Train 21명/2349장, Validation 6명/599장. 검증 환자는 G06/G07/G09/G14/G17/G20으로 고정합니다.
- 동일 VGG의 4096차원 특징을 한 번 추출한 뒤 출력층 준비 학습에 재사용합니다. 이 단계에서는 기존 dropout을 끄며, 다른 신경망은 사용하지 않습니다.
- 이미지 디코딩/336×224 리사이즈를 메모리에 캐시합니다. AMP와 channels-last를 사용합니다. 실제 속도는 GPU와 Drive 상태에 따라 다릅니다.
- 학습에만 좌우 반전, ±5도 회전, 밝기/대비 ±10%를 적용합니다. CLAHE, 백분위 보정, 무작위 crop은 적용하지 않습니다.
- 약한 label smoothing 0.03과 AdamW를 사용합니다. 두 epoch 동안 뒤쪽 합성곱과 전체 FC를 적응시킨 뒤 전체 블록을 미세조정합니다. 앞쪽 특징은 더 작은 학습률을 씁니다.
- 두 후보는 같은 준비 학습 가중치에서 독립적으로 시작합니다. A는 클래스 균형 손실, B는 같은 클래스별 총 가중치를 유지하며 환자×클래스 빈도의 제곱근 역수로 환자 비중을 완만하게 조정한 손실입니다. 각 epoch에 이미지당 한 번 사용하므로 희귀 환자 이미지를 반복 복제하지 않습니다.
- 각 epoch의 임계값 조정 BA를 우선하여 가중치를 선택합니다. 동률은 AUROC로 결정합니다. epoch, 임계값, 후보 모두 같은 Validation으로 선택하므로 과대평가될 수 있으며 **독립 Test 점수가 아닙니다**.
- 새로운 두 후보 중 하나만 선택합니다. 앙상블/TTA는 없으며 전체 데이터 재학습도 하지 않습니다.

## 시간과 출력

출력층 준비 학습을 두 후보가 공유합니다. 후보당 최대 12 epoch, patience 4이며 전체 미세조정에 기본 35분을 나눠 배정합니다. 이미지 캐시, 사전학습 가중치 다운로드, 최초 평가 및 최종 파일 저장 시간은 별도라서 전체 35분 완료를 보장하지 않습니다. 후보별 예산은 동일하고 조기 종료로 남은 시간은 다른 후보에 추가하지 않습니다.

가중치는 Drive의 `task2_vgg_research/<실행시간>/<후보>/vgg.pt`에 보관합니다. 최고 가중치를 3 epoch마다 및 후보 종료 시 복사합니다. 자동 재개 기능은 없습니다. `inference.py`는 저장된 전처리 및 임계값으로 단일 원본 프레임을 추론합니다. GPU/CPU 추론의 수치 차이는 있을 수 있습니다.

완료 시 `vgg_research_report.zip`만 다운로드합니다. 큰 모델 파일은 ZIP에 포함하지 않습니다. 새 후보가 첫 모델의 재계산 BA를 넘지 못하면 코드가 그 사실을 알립니다. 원래 첫 모델을 자동 교체하지 않습니다.

## 참고와 적용 범위

- [Kumar et al., ICLR 2022: LP-FT](https://arxiv.org/abs/2202.10054), [저자 공개 구현](https://github.com/AnanyaKumar/transfer_learning). 출력층 준비 후 전체 미세조정의 근거이며 본 과제에서의 개선 보장은 아닙니다.
- [Davila et al., 2024: 의료 영상 미세조정 비교](https://arxiv.org/abs/2406.10050). 모델/영상 도메인에 따라 효과가 달라지므로 VGG에서 동결을 일률적으로 늘리지 않습니다.
- [Müller et al., NeurIPS 2019: label smoothing](https://arxiv.org/abs/1906.02629). 과도한 확신 완화의 근거이며 0.03은 본 실험의 선택입니다.
- [PyTorch channels-last/AMP 안내](https://docs.pytorch.org/tutorials/intermediate/memory_format_tutorial.html). 실행 속도 최적화이며 BA 개선 기법은 아닙니다.
- 환자별 손실 비중은 이 데이터에서 검증할 별도 가설입니다. 논문에 나온 최적 설정이라고 주장하지 않습니다.

정적 문법, 동점 점수를 포함한 ROC/임계값 계산 100개 사례, 첫 모델의 실제 예측값, 학습 데이터의 손실 가중치를 확인했습니다. 작성 환경에는 torch가 없어 학습/추론 전체 실행은 검증하지 않았습니다. 원본 데이터/가중치는 GitHub에 올리지 않습니다.
